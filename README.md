# Grade Calculator

A simple **Grade Calculator built using JavaScript** that accepts marks of 5 subjects, calculates the total marks and percentage, and assigns a grade based on the percentage.

## 📌 Features

* Accepts marks for 5 subjects from the user.
* Calculates the total marks.
* Calculates the percentage.
* Assigns a grade using `if...else if` conditions.
* Displays the final grade in the browser console.

## 🛠️ Technologies Used

* JavaScript
* `prompt()` for taking user input
* `console.log()` for displaying output

## 📊 Grading System

| Percentage | Grade |
| ---------- | ----- |
| 90–100     | A     |
| 70–89      | B     |
| 60–69      | C     |
| 50–59      | D     |
| 0–49       | F     |

## 🚀 How to Run

1. Download or clone this repository.
2. Open the JavaScript file in a browser environment.
3. Enter marks for all 5 subjects when prompted.
4. Open the browser's **Developer Console** to view the grade.

## 💡 Example

If the user enters:

```text
Subject 1: 80
Subject 2: 90
Subject 3: 75
Subject 4: 85
Subject 5: 70
```

The program calculates:

```text
Total = 400
Percentage = 80%
Grade = B
```
